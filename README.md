# projects
Portfólio — publicação no GitHub Pages

1. Abra o repositório `italogaldino-cmd.github.io` no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório, substituindo o `index.html` anterior.
3. Confirme que `index.html`, `style.css`, `script.js`, `favicon.svg` e `404.html` estão na raiz (não dentro de outra pasta).
4. Aguarde o GitHub Pages atualizar e abra `https://italogaldino-cmd.github.io`.
